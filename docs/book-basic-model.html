Reconstructed rulebook · Chapter 2

Reading a HYBRID rating

Keep three pieces together

Read 20 C2 DP as three pieces of information. The number is 20. C2 selects a numerical scale. DP identifies the quantity as default psyche. Changing any one of the three may change the character being described. LS stands for life-span and PL for power level. Keep the scale label even when an entry eventually yields a familiar unit such as miles per hour or years.

Translate a number to a neighbouring scale

Rule 45 gives the map between several neighbouring scales. In a C2-to-C3 conversion, raise the C2 number to the power of its own base-ten logarithm. A value of 20 C2 DP therefore becomes about 49.28 C3 DP. The character retains the same rating expressed on another scale. Rule 46 shows why doubling before conversion gives a different number from doubling afterward.

What a player can change

Rule 3 pairs changes in LS and PL around an unchanged DP. Its examples include moving equal amounts in opposite directions and multiplying one quantity while dividing the other by the same factor. The first preserves a sum, the second a product. The two operations create different characters from the same starting numbers. The text supplies examples of both and does not give a general rule for choosing between them.

What counts as an outcome

A computed speed, a change in a rating and a successful roll are different kinds of result. Only some passages tell us which fictional event follows. Treat each question locally. A definition of running speed answers a question about pace. To settle an interrupted journey would also require rules for the interruption.
