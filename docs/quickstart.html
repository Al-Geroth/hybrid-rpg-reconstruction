At the table

Quickstart

Give the sheet a starting point

Write a name and the words 16 C2 DP. This is the ordinary-human example in Rule 49. The number is the baseline. C2 tells you which scale it belongs to, and DP means default psyche. The GM sets the campaign scale in Rule 11. Rule 47 gives a fuller write-up with age, COM and a remainder for powers. For this exercise the baseline is enough.

Read one number two ways

Take the square root of 16. You now have an average Mind, Body and Soul rating of 4. Next raise 16 to the power of log₁₀(16). The answer, about 28.18, is the same baseline expressed as C3 DP. Neither operation spends a point.

Try a physical action

Can this character keep pace with a parade moving at 3 mph? Rule 39 requires 10 × (1 + log₁₀(3)), about 14.77 C2 DP or PL. The character has 16 C2 DP. On the reading that a higher running rating meets a lower pace requirement, the character can keep up. The rule also gives a direct benchmark when the ratings match exactly. A 20 C2 runner meets the stated requirement for 10 mph. No roll is specified by the speed rule.

Give one specialist a power

For a different character, follow the choices in Rule 123. Start at 9 C2 DP. Select agility for the first advantage and multiply by 2. Select increased height for the second and multiply by 1.5. Select camouflage for the third and multiply by 4/3. The resulting character has 36 C2 DP and those named traits. The text does not give a detection contest for this combination.

Try a change with a cost

Rule 183 describes a character starting at 40 C2 DP. For the power in that example, doubling power to 80 C2 PL pairs with halving life-span to 20 C2 LS. The baseline stays at 40. This example gives a particular multiplier and effect. Rule 3 also permits addition, roots and other paired operations, so the multiplier cannot be inferred for every new power.

What you can play through

One exchange has a clear beginning and end. Declare a pace, calculate its requirement and see whether the ordinary runner meets it. The same group can generate a character and rate some fantastic powers. An encounter in which opponents act, suffer effects, recover and receive advancement goes beyond this quickstart because the surviving procedures fail to connect those stages. The playability trials show exactly where each test stops.
