Reconstructed rulebook · Chapter 8

What persists into another session?

An effect can end

The clearest example of persistence concerns an effect. Rule 45 allows the creator to regain an earlier status when a creation wears off. Rule 128 distinguishes certain temporary copies from lasting ones. A GM could record the current ratings and whether the effect is still present. Neither passage supplies an expiry time that every table would independently recover.

Source passages · #45 · #128

Reincarnation has a waiting time

Rule 87 does give one time interval following a declared death. For the class of beings specified there, squaring the C3 rating gives years until a new body. The author qualifies its application to other beings and dimensions. It supplies neither the condition that declares an ordinary character dead nor an instruction for what survives on the new sheet.

A · Explicit original mechanic

Source passages · #87

Advancement means something more specific

Adding the second and third advantages in Rule 123 is a character-building sequence. Rule 125 discusses experience-like letter grades in a comparison with Marvel SAGA. Rule 0 ties a version number to years. None of these passages awards a character points for events at the table. We could carry the values on the sheet forward, but could not calculate an earned increase after a session from this edition.
