Vocabulary

Glossary

A rating in HYBRID has three parts to keep track of. Its number, class and use can each change what the other two mean.

#− / roll under

Target or less

An integer target followed by a minus sign represents a roll equal to or below that target.

Use
Tests a desired rating or behavioral state in a set of examples influenced by HERO.
Units or domain
Die total and inclusive integer upper bound.
Uncertainty
This minus sign does not mean subtract one. #188 explicitly marks a conflict with #17.
Interpretation

Source passages · #188

2×C / C×2

Ordered multiplier notation

Notation which distinguishes doubling a class numeral from doubling an input before it is converted.

Use
Makes explicit that a nonlinear transform does not commute with multiplication.
Units or domain
Class-specific numerical values whose order of operations matters.
Example
Doubling f(20) gives about 98.56, whereas f(2×20) gives about 368.63.
Uncertainty
Numbers near 98.56 and 368.63 can both occur in the same example but refer to different operations.
Interpretation
High · A · Explicit original mechanic
Related
c2 · c3 · magnitude

AMBS

Average Mind, Body and Soul

An aggregate of three named character aspects derived from the square root of C2 DP.

Use
Converts a baseline into a compact attribute score. Some build examples use AMBS milestones.
Units or domain
Nonnegative square root of the numerical C2 DP rating.
Example
A baseline of 64 produces 8 AMBS.
Uncertainty
The source gives an average. Individual values cannot be recovered from it without another constraint.

C0

Context-specific scale zero

A label assigned to a local output, such as Psyche, strength, material strength, a ghost reading or immortality.

Use
Gives a reported value for a particular subject and comparison.
Units or domain
Different numerical relations depending on the statistic and the subject.
Example
In #5, 100 C1 DP can produce 50 C0 Psyche on one named reading, or directly 100 on another.
Uncertainty
The sequence CA → C1 → C2 does not imply C0 → C1 via the same transform.

DP

Default Psyche

A baseline magnitude from which the source describes departures in lifespan and power.

Use
During a #3 trade the baseline stays fixed. Character creation examples assign DP by a die total. A fictional effect may instead change the baseline itself.

A numerical rating on a named class, e.g. 40 C2 DP.
